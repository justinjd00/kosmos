Nothing computed here is worth much if it cannot leave the page.

| Format | Contents |
|---|---|
| SVG | The 2D structural formula, vector, publication ready |
| PNG | The 3D view at print resolution, not screen resolution |
| MOL (V2000) | Connectivity plus 2D or 3D coordinates |
| SDF | MOL plus the computed properties as data fields |
| XYZ | Elements and 3D coordinates |
| PDB | For anything that expects it |
| CSV | The property table, one row per quantity, with the method column from #1 |
| JSON | Everything at once, for scripting |

Requirements:

- Every writer round-trips: what is written must parse back to the same molecule. Test that.
- MOL and SDF must be readable by other software; check the output against the format specification rather than against our own reader alone.
- The exported numbers must be the numbers on screen, to the last digit shown. No separate formatting path.

Depends on #1 and #3.
