`Ctrl`/`Cmd` + `K`. One field that reaches everything.

- every module and every preset — `lorenz`, `double slit`, `dipole`
- every worked example — `aspirin`, `caffeine`, `glucose`
- every action — export SVG, copy link, toggle theme, clear walls
- every function in the expression language, with its signature and arity shown inline
- every physical constant, insertable at the cursor

Type `sin` and it goes into the formula. Type `aspirin` and the molecule loads. Type `svg` and the export runs. Fuzzy matched, ranked by what you use, arrow keys and Enter, Escape closes and returns focus where it was.

This is the difference between a page someone visits once and a tool someone lives in. It is also the cheapest accessibility win in the whole project: every action becomes reachable without a mouse, by name.

On touch, the same palette opens from a button in the header — the search field is not a desktop-only affordance.

Built from the Combobox and Search input primitives in #13. Must be fully operable by keyboard and announce its result count to a screen reader (#16).
