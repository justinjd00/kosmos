Mermaid did not spread because its website was good. It spread because GitHub rendered it inside other people's pages. Distribution through an existing surface beats a destination every time.

## Three levels

**Custom elements.** One script tag, then:

```html
<script type="module" src="https://.../kosmos.js"></script>

<kosmos-plot expr="sin(x)/x" domain="-20,20"></kosmos-plot>
<kosmos-molecule smiles="CC(=O)Oc1ccccc1C(=O)O" view="2d"></kosmos-molecule>
<kosmos-field preset="double-slit" playing></kosmos-field>
```

Standard web components, no framework, working in a blog, a docs site, a wiki, an LMS page, a Jupyter output cell, a Slidev deck. Attributes are the API and they are the same vocabulary as the permalink (#20).

**Iframe with a documented URL contract**, for anywhere a script tag is not allowed — which is most content management systems and every LMS worth worrying about.

**oEmbed**, so pasting a kosmos link into a wiki, Notion, Discourse or a CMS unfurls into the live thing rather than a bare link.

## Non-negotiables

- Degrades to a static SVG when scripting is off or the WASM fails to load. An embed that shows an empty box in a published paper is worse than no embed.
- Lazy: nothing loads until the element is near the viewport. A page with twelve embeds must not download the engine twelve times or on first paint.
- **Does not phone home.** No analytics, no font CDN, no telemetry. Someone embedding this on their page is vouching for it; that trust is the whole asset.
- Respects the host page's `prefers-color-scheme` and reduced-motion settings.
