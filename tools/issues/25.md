Things that live in Makefiles do not get replaced.

```sh
kosmos d/dx "sin(x^2)"
kosmos integrate "x*e^x"
kosmos solve "x^2 - 5x + 6 = 0"
kosmos mol "CC(=O)Oc1ccccc1C(=O)O" --svg figure.svg --csv properties.csv
kosmos field double-slit --seconds 8 --out interference.png
```

## Requirements

- Reads stdin, writes stdout, exits non-zero on failure. A tool that cannot be piped is a tool that cannot be scripted.
- `--json` on everything, with the same shape as the library (#23) and the same method records as #1.
- Static binaries for the three platforms, plus Homebrew, scoop and a `.deb`. `curl | sh` is not an installation method anyone in a regulated environment is allowed to use.
- No network access at runtime, ever. Announced, and tested.
- `--version` prints the version and the DOI (#18), so a shell script's output can say what produced it.

This is also how kosmos gets into other people's continuous integration — a chemistry group that regenerates its figures on every commit is a group that will notice immediately if we break something, which is worth more than any amount of goodwill.
