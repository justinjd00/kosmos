The second half of the request that started this: a biologist should be able to paste a sequence and get something correct out.

**Reading:** FASTA, plain sequence, multi-record files. DNA, RNA and protein alphabets including the IUPAC ambiguity codes.

**Computed, each with its source:**

- length, base composition, GC content, and GC content along a sliding window
- reverse complement, transcription, translation with selectable codon tables
- open reading frames, with a minimum length and both strands
- molecular weight of the strand
- melting temperature by nearest neighbour, after SantaLucia 1998, with salt and concentration as parameters
- restriction sites for the common enzymes

**Drawn:**

- 2D: a sequence map with features, the GC window plot, ORFs on both strands
- 3D: B-DNA built from measured helical parameters — 3.32 A rise, 34.3 degrees twist, 10.5 base pairs per turn — with correct Watson-Crick pairing. A-form and Z-form later.

**Export:** FASTA, GenBank feature table, CSV of the computed quantities, SVG of the map, PDB of the helix.

Same rule as everywhere else: the helix is built from published parameters, not measured, and must say so.
