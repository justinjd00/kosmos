A tool that cannot be cited does not become a norm. If someone uses kosmos for a figure or a number in a paper, a thesis, or a report, there has to be something to put in the bibliography — and it has to name the exact version, because the number they got came from that version and not another.

## What to build

- **`CITATION.cff`** in the repository root, so GitHub shows a "Cite this repository" button and every tool that reads the standard picks it up automatically.
- **Zenodo linked to the repository**, so every GitHub release mints a DOI without anyone doing anything. Zenodo also mints a *concept DOI* that always resolves to the newest version — cite the concept DOI for "kosmos", the version DOI for "the number in table 3".
- **"Cite this" in the interface**, producing BibTeX, RIS and a plain APA string, with the running version and its DOI already filled in. One click, copied.
- **The same string in every export's provenance stamp** (#6), so a figure carries its own citation even after it has been pasted into a slide deck and emailed twice.

## Why this is first, not last

It costs an afternoon and it is retroactive in exactly one direction: releases made before it exists can never be cited properly, and releases made after it always can. Every week it is delayed is a week of releases nobody can reference.
