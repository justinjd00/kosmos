Science runs on Python. This is the single largest lever in the whole roadmap for getting into actual laboratories, because it puts kosmos where the work already happens instead of asking people to come to a website.

```
pip install kosmos
```

```python
import kosmos

m = kosmos.molecule("CC(=O)Oc1ccccc1C(=O)O")
m.formula          # 'C9H8O4'
m.monoisotopic     # 180.042258...
m.tpsa             # 63.60
m                  # renders the structure inline in Jupyter
```

## Requirements

- **The same Rust core**, bound through PyO3. Not a reimplementation — a second implementation is a second set of bugs and a guarantee that the two will disagree.
- **Wheels for Linux, macOS and Windows**, built in CI, so `pip install` never needs a compiler.
- **NumPy in and out** for anything vectorised: sample a function over an array, integrate a system over a time grid.
- **A Jupyter `_repr_html_`** so a molecule draws itself in a notebook and a plot appears without ceremony. This is what makes people show it to a colleague.
- The same method records as #1, exposed as data, so a script can carry provenance into a pipeline.

An analysis script that imports kosmos and produces a figure is worth more for adoption than a thousand people visiting the website once.

Depends on #1 and #3 for anything molecular to be useful. Related: #23, #25.
