The fourth module in the interface, alongside Functions, Chaos and Fields.

- An input field taking SMILES, with the same character-position error reporting the expression parser already has.
- A few worked examples to start from: aspirin, caffeine, glucose, cholesterol, paracetamol.
- Structural formula and 3D view side by side, both reacting to the same input.
- The property table from #1, each row showing the method it used.
- Export buttons from #5.
- Deep links, in the shape the other modules already use: `#molecules/<smiles>`.

Depends on #1, #2, #4, #5.
