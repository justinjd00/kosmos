The OCaml module integrates a useful fragment but stops at rational functions.

- **Partial fractions.** `∫ 1/((x-1)(x+2)) dx` should work. Needs the denominator factored over the rationals, then the decomposition, then term-by-term integration.
- **Factoring over the rationals.** Rational root search for the linear factors, then square-free decomposition; Kronecker or a small Zassenhaus for the rest.

Both need exact arithmetic. `Num of float` cannot represent 1/3 without drift, so this wants either a `Rat` constructor beside it or a separate polynomial representation translated into only for these operations — probably the latter, since it leaves the rest of the module untouched.

Everything new must keep the existing guarantee: an antiderivative is differentiated again and checked numerically before it is returned, so a failed factorisation produces a refusal rather than a wrong answer. Add the new cases to `cas/expected.txt`, which is what `core/tests/algebra.rs` holds the Rust engine to.
