The engine is a Rust crate compiled to WebAssembly that currently has exactly one consumer: the web app in this repository. It should be a library anyone can install.

```
npm i @kosmos/engine
```

```js
import { parse, derivative, integrate } from "@kosmos/engine";

const f = parse("sin(x^2)");
derivative(f);        // cos(x^2)*2*x
integrate("x*e^x");   // x*e^x - e^x
```

## Requirements

- **No DOM dependency.** Runs in Node, Deno, Bun, a web worker, and a browser. The engine does mathematics; it should not know what a canvas is.
- **TypeScript types generated from the Rust**, not hand-written and drifting.
- **A documented, stable, semantically versioned API.** The point of a library is that it does not move under you.
- **The web app becomes the first consumer of its own public API.** This is the only mechanism that keeps the API honest — if the app reaches into internals, the internals are the API, and everyone else gets a worse one.
- Tree-shakeable, so a page that only wants to parse an expression does not ship the whole simulation.

The line between this and a hobby project is whether someone else can build something on it without asking permission.
